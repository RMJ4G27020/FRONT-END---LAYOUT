Holy Grail Layout

Classic three-column layout with header and footer

About the Holy Grail Layout

The Holy Grail layout is a classic web design pattern featuring:

  • A header spanning the full width
  • Three columns (left sidebar, main content, right sidebar)
  • A footer spanning the full width
  • The main content column should appear first in the HTML (for SEO)
  • All columns should be of equal height
  • Responsive behavior on smaller screens

This was historically difficult to implement with CSS, but modern layout methods (CSS Grid and Flexbox) make it straightforward.

Grid vs Flexbox for Holy Grail

CSS Grid Advantages:

  • Cleaner, more intuitive code
  • Template areas make layout visual in CSS
  • Better for two-dimensional layouts
  • Easier responsive transformations

Flexbox Advantages:

  • Better browser support (older browsers)
  • More intuitive for developers familiar with Flexbox
  • Good for simpler layouts
  • Easier to reason about flex-grow behavior

Recommendation:

Use CSS Grid for the Holy Grail layout. It was designed for exactly this type of two-dimensional layout and results in cleaner, more maintainable code.
