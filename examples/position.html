CSS Position Examples

Understanding static, relative, absolute, fixed, and sticky positioning

Position Property Overview

The CSS position property determines how an element is positioned in the document. Each position type behaves differently and is useful for specific layout scenarios.

  • static: Default positioning, follows normal document flow
  • relative: Positioned relative to its normal position
  • absolute: Positioned relative to nearest positioned ancestor
  • fixed: Positioned relative to the viewport
  • sticky: Toggles between relative and fixed

1. Static Positioning (Default)

Elements appear in normal document flow. Top, right, bottom, left have no effect.

Static Box (Default)

This is regular content that flows normally.

.static-box { position: static; /* Default, usually not specified */ }

4. Fixed Positioning

Positioned relative to the viewport. Stays in place when scrolling.

Note: Look at the bottom-right corner of your screen. There's a fixed "↑" button that stays visible as you scroll.
.fixed-button { position: fixed; bottom: 30px; right: 30px; z-index: 1000; } /* Stays in the same position even when scrolling */

6. Practical Example: Modal

Using fixed positioning for overlays and modals

Modal Dialog

This modal uses fixed positioning to overlay the entire viewport.

The overlay background is also fixed to cover the whole screen.

.modal-overlay { position: fixed; top: 0; left: 0; right: 0; bottom: 0; background: rgba(0, 0, 0, 0.5); display: flex; align-items: center; justify-content: center; z-index: 1000; } .modal-content { position: relative; background: white; padding: 2rem; border-radius: 12px; }

Position Best Practices

Tips:

  • Minimize absolute positioning: Use Flexbox or Grid for most layouts
  • Positioning context: Remember absolute positions relative to nearest positioned ancestor
  • Z-index management: Use consistent z-index scale (e.g., 10, 20, 30)
  • Fixed elements: Ensure they don't block important content on small screens
  • Sticky support: Provide fallback for older browsers
  • Accessibility: Ensure positioned elements maintain logical tab order
  • Performance: Fixed and sticky can cause repaint issues if overused
